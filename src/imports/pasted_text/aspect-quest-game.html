Create a complete playable browser game called **"Aspect Quest"**. GAME TYPE 2D platformer similar to classic Mario-style games. TECH STACK Use HTML5 Canvas + JavaScript (no heavy frameworks). The game must run directly in the browser. VISUAL STYLE Pixel art style. Retro arcade feeling. GAME STORY The game takes place in **Fethiye**, a chaotic restaurant world full of tourists, fish markets, chefs and seagulls. The player is a **photographer hero** called **Aspect Photographer**. The mission is to collect photos to become the **legendary photographer**. GAME SLOGAN "Capture the Chaos" GAME MECHANICS Movement: * Move left * Move right * Jump * Double jump Attack: Camera Flash Camera flash temporarily stuns enemies. HEALTH SYSTEM Player has 3 hearts. ITEMS Collectible item: Photos Rare collectible: Legendary Photo LEVEL STRUCTURE Create 10 levels. Each level lasts about 5 minutes.
